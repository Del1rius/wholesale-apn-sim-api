   API Call:
   
   curl -X POST http://localhost:8000/api/usage/usage-records/ \
     -H "Content-Type: application/json" \
     -u admin_user:AdminPass123! \
     -d '{
       "sim_card": "<ALICE_SIM_UUID>",
       "billing_cycle": "<ACTIVE_CYCLE_UUID>",
       "data_consumed_mb": 600.0,

   ✓ HTTP 201 Created
   ✓ Celery task triggered immediately

   5. SIM status changed: 'assigned' → 'suspended'
   6. Database updated automatically
   7. Process completes in < 2 seconds

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Issue 1: Celery task not triggering
Solution:
  docker-compose restart celery
  docker-compose logs celery --tail=20
  Ensure Redis is running: docker-compose ps redis

Issue 2: SIM not suspending automatically
Checks:
  □ Celery worker is running
  □ Total usage exceeds limit (query usage records)
  □ SIM status was 'assigned' before logging usage
  □ Check Celery logs for task execution

Issue 3: Dashboard not updating
Solution:
  □ Hard refresh browser (Ctrl+F5)
  □ Clear browser cache
  □ Check if static files are served: docker-compose exec web python manage.py collectstatic --noinput

Issue 4: Can't login with demo credentials
Solution:
  □ Reseed database: docker-compose exec web python manage.py seed_database
  □ Check user exists: docker-compose exec web python manage.py shell
    >>> from users.models import User
    >>> User.objects.filter(username='admin_user').exists()

Issue 5: API returns 401 Unauthorized
Solution:
  □ Check credentials are correct
  □ Use curl -u username:password for Basic Auth
  □ For JWT: Get token first from /api/token/ endpoint
